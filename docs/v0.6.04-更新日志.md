### 1.2 每条包含的内容

- **需求等级** —— 按所需最高符文的等级需求计算，与已收录条目口径一致
- **符文图标** —— 直接显示需要哪些符文、按什么顺序
- **属性气泡** —— 完整列出所有属性，有区间的标「(变动)」
- **镶材与符文** —— 符文名称与编号，以及可用底材类型

## 二、这些数据从哪来

全部由游戏数据表自动生成：

| 项目 | 来源 |
|---|---|
| 需求等级 | misc.txt 各符文 levelreq 的最大值（最小 1） |
| 中文名 | item-runes.json 对应条目首行 |
| 属性文案 | runes.txt 的 T1Code1~7 / T1Min / T1Max / T1Param |
| 符文图标 | Rune1~6 → $FileRune{N} |
| 列表位置 | 追加在已有条目之后，y 递增 60 |
| 字符串 id | 全表 max(id) + 1 |

以后 runes.txt 若有增删，可用配套工具一键同步。

## 四、配套工具（供维护者）

```
检查（不修改）
  python sync_runeword_wiki.py --dry-run

实际写入（自动备份）
  python sync_runeword_wiki.py
```

自动比对、生成、写入、校验；写入前自动备份，遇到未知属性代码会警告。
工具不随 mod 包分发。
