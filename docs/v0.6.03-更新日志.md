## 一、本次修复

### 1.1 佣兵阵亡后无法复活

- **现象**：启用模组后，佣兵阵亡，回城找佣兵商人复活无效。
- **影响**：罗格射手、沙漠佣兵、铁狼法师、第四幕死灵、第五幕野蛮人 —— 五种佣兵都可能出现。
- **严重性**：高。

**根因**

问题出在佣兵表 `hireling.txt` 的**行顺序**，不在任何佣兵的具体属性。

模组在表里新增了两批佣兵：

- 9 行东方法师（噩梦 15 级档、地狱 15 级与 49 级档）
- 24 行第四幕死灵法师

这 33 行被插在了表格**中间**（从第 97 行开始），导致其后所有行整体后移：

| 行号 | 原版内容 | 模组改后内容 |
|---|---|---|
| 第 97 行 | 东方法师 ID 18 / 难度 2 / 49 级 | 东方法师 ID 18 / 难度 2 / **15 级**（新插入） |
| 第 98 行 | 东方法师 ID 18 / 难度 2 / 79 级 | 东方法师 ID 18 / 难度 2 / 49 级 |
| 第 99 行 | 东方法师 ID 19 / 难度 2 / 49 级 | 东方法师 ID 18 / 难度 2 / 79 级 |

存档里记录的佣兵信息按表格**位置**索引。玩家在装模组之前雇的佣兵，位置对应原版表格；
装上模组后同一位置指向另一个佣兵，复活时数据对不上，流程中断。

**修复方式**

```
第 1 ~ 135 行     原版 135 行，顺序完全不动
第 136 ~ 144 行   新增的 9 行东方法师
第 145 ~ 168 行   新增的 24 行第四幕死灵
```

**验证结果**

五种佣兵全部可正常复活；普通/噩梦/地狱三个难度的雇佣列表均正常。

## 二、升级说明

- **覆盖安装**：替换旧的 shu 模组目录，无需重新开档。
- **必须重新编译**：若安装里存在旧的 `.bin`，请执行 `d2rl compile shu`，
  或删除 `Data\global\excel` 下全部 `.bin`。
- **老存档**：此前复活失败的佣兵，更新后重新进游戏即可复活。
